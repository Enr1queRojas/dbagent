# Flujo de análisis

1. Entender la pregunta de negocio y el periodo.
2. Cuando exista una herramienta de catálogo, descubrir tablas y relaciones.
3. Acordar definición de métricas, granularidad y filtros.
4. Cuando exista una herramienta autorizada, consultar solo los datos necesarios.
5. Verificar nulos, duplicados, joins y coherencia de totales.
6. Presentar resultados con fuente, periodo, unidades y limitaciones.

Esta skill es una guía textual. No ejecuta SQL ni otorga permisos.
